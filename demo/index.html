Prism PDF starting… Nothing is uploaded

Take a PDF apart without uploading it.

This page runs Prism PDF — a PDF engine written in Rust, compiled to WebAssembly — inside your browser tab. Read the text, walk the structure, pull out the images and attachments, reorder or drop pages, and write the file back out. Your document never leaves the tab, because there is nowhere for it to go: the page makes no request to any other server.

Start with a document

The sample is four pages written from nothing by this repository's build script, with an outline, links, two raw images, a form field, an attachment and an XMP packet — one of each, so every panel has something to show. Or hand it a file of your own.

Or drop a PDF anywhere on this page.

One module, no bundler
A single-threaded WebAssembly module, loaded exactly as npm i prism-pdf gives it to you. Its transfer size is in the bar above, read from the browser rather than typed in here.
Every number here is measured
Each panel reports what the engine did and how long the call took, taken from performance.now() around the call itself.
Page pictures are pdf.js's
Prism has no rasterizer, so previews and thumbnails are drawn by Mozilla's pdf.js, vendored beside this page and labelled wherever it appears.
